I found a Notion-based to-do app design on Dribbble and rebuilt it from scratch using vanilla JavaScript and Tailwind CSS, no frameworks.

The result is a fully functional task manager that supports creating tasks with priorities, due dates, and subtasks, filtering by All Tasks, Today, Upcoming, and Completed, real-time search, an animated progress ring, a distraction-free Focus mode, full dark mode, and a responsive mobile layout.

This was by far the most complex project I've built, taking about four months. I learned to structure an app across multiple JavaScript files, manage shared state across features, debug closures and scope issues, and build custom CSS animations including an SVG progress ring. I also ran into and fixed several real responsive-design bugs, which taught me a lot about how CSS breakpoints and positioning actually behave in practice.

Although I'm proud of how far this pushed my understanding, I know there's more to learn — my next step is applying what I built here to React.
